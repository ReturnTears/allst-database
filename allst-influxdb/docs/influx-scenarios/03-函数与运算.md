# 03 函数与运算

## 场景

平均值、最大最小值、变化率和单位换算放在 InfluxDB 里算。应用只接收桶，不接收原始点。

所有函数接口都要带 `metricType`。`device_metric` 里同时有温度和电压，不带类型就做 `mean(value)`，得到的数没有意义。

## 可以用的函数

聚合，参数 `fn`：

`mean`、`max`、`min`、`sum`、`count`、`stddev`、`spread`、`median`、`first`、`last`、`percentile`

`percentile` 还要传 `percentile=95`，范围 0 到 100。

变换，参数 `fn`：

| 函数 | 用途 |
| --- | --- |
| `derivative` | 每个桶均值的变化速度。仪表、温度这一类用它 |
| `non_negative_derivative` | 计数器。计数器重置时不把差值算成负数 |
| `difference` | 相邻桶均值的差 |
| `moving_average` | 对桶均值做滑动平均，`points` 默认 5，最大 100 |
| `cumulative_sum` | 桶均值的累计 |
| `elapsed` | 相邻桶之间过了多久 |

固定运算，参数 `expr`，不接受一段自由公式：

| expr | 语句 |
| --- | --- |
| `celsius_to_fahrenheit` | `mean(value) * 9 / 5 + 32` |
| `milli_scale` | `mean(value) * 1000` |
| `abs_mean` | `abs(mean(value))` |

新的业务公式加在 `AnalyticsStatements` 里，不要做“把表达式字符串交给数据库”。

## 窗口

`window` 默认 `1m`。只允许 `10s`、`30s`、`1m`、`5m`、`10m`、`15m`、`30m`、`1h`、`6h`、`12h`、`1d`。

`fill` 默认 `none`，也允许 `null`、`linear`、`previous`、`0`。`none` 会丢掉空桶，图上的时间轴不会自动补点。

`limit` 默认 2000，最大 10000。`SLIMIT 20` 限制最多返回 20 条 series。不传 `deviceId` 时，超过 20 台设备的结果会被截断。

时间范围最长 7 天。7 天、1 分钟一个桶，大约 10080 个点，所以最大 limit 放到 10000。

## 代码

- `com.allst.boot.analytics.AnalyticsService`
- `com.allst.boot.influx.sql.AnalyticsStatements`

语句形态：

```sql
SELECT mean("value") AS "value"
FROM "rp_raw_7d"."device_metric"
WHERE time >= ... AND time < ... AND "metric_type" = 'temperature'
GROUP BY time(1m), "device_id", "region", "metric_type"
FILL(none)
LIMIT 2000
SLIMIT 20
```

连续查询用 `GROUP BY *`，是为了以后新增 tag 时降采样不会丢 series。在线查询把 tag 写死，避免把高基数 tag 意外卷进来。

## 接口

| 方法 | 路径 |
| --- | --- |
| GET | `/api/influx/analytics/aggregate` |
| GET | `/api/influx/analytics/transform` |
| GET | `/api/influx/analytics/calculate` |

公共参数：`metricType`、`deviceId`、`region`、`range` 或 `start/end`、`window`、`fill`、`limit`。

## 调用示例

```bat
curl.exe "http://127.0.0.1:8091/api/influx/analytics/aggregate?fn=mean&metricType=temperature&deviceId=dev-001&range=6h&window=5m"
curl.exe "http://127.0.0.1:8091/api/influx/analytics/aggregate?fn=percentile&percentile=95&metricType=temperature&deviceId=dev-001&range=6h&window=5m"
curl.exe "http://127.0.0.1:8091/api/influx/analytics/transform?fn=derivative&metricType=temperature&deviceId=dev-001&range=6h&window=1m&unit=1m"
curl.exe "http://127.0.0.1:8091/api/influx/analytics/calculate?expr=celsius_to_fahrenheit&metricType=temperature&deviceId=dev-001&range=6h&window=5m"
```

## 生产环境要注意

- `derivative` 套在 `mean()` 外面，算的是桶之间的变化，不是原始点之间的变化。桶越大，曲线越平滑。
- 计数器重置用 `non_negative_derivative`。温度这种会升降的量不要用它，下降会被抹成空桶。
- `moving_average` 开头几个桶因为点数不够，会是空的。`fill=none` 时这些桶不返回。
