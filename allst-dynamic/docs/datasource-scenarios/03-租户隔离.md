# 租户隔离

每个租户一个库。请求头 `X-Tenant-Id` 决定数据源，业务 SQL 不再拼租户条件。适合库级隔离。行级隔离（同一张表加 `tenant_id`）不是这里的做法。

## 内置租户

| 请求头 | 数据源 | 库 |
| --- | --- | --- |
| `a` | `tenantA` | `dyn_tenant_a` |
| `b` | `tenantB` | `dyn_tenant_b` |

两个库都有 `t_account` 和 `t_ledger`。没有请求头时账号接口直接 400，避免落到默认库把租户串在一起。

`TenantContextFilter` 只处理 URI 里包含 `/scenario/tenant` 的请求，把请求头放进 `TenantContextHolder`。Service 用 `TenantDirectory` 把租户 id 换成数据源键。

## 运行时注册

新租户不重启应用。先在 MySQL 里建库建表，再调用注册接口。数据源名是 `rtTenant` 加租户 id，例如租户 `c` 得到 `rtTenantc`。名字里不能有下划线，否则会被当成负载均衡组。

租户 id 规则：小写字母开头，后面只能是小写字母或数字，最长 16 位。`a`、`b` 是内置租户，不能重复注册，也不能摘除。

```bat
curl.exe -X POST http://127.0.0.1:8000/dynamic/scenario/tenant/datasources -H "Content-Type: application/json" -d "{\"tenantId\":\"c\",\"url\":\"jdbc:mysql://localhost:3306/dyn_tenant_c?useUnicode=true&characterEncoding=utf-8&useSSL=true&serverTimezone=Asia/Shanghai\",\"username\":\"root\",\"password\":\"\"}"
curl.exe -X DELETE http://127.0.0.1:8000/dynamic/scenario/tenant/datasources/c
```

这个接口没有鉴权，和当前练习工程的其它接口一样。生产环境必须限制调用方，并限制 JDBC 地址的主机范围。

## 代码

- `TenantKeys`、`TenantDirectory`：租户到数据源键
- `TenantAccountServiceImpl`：账号读写
- `LedgerWriter`：`@DS("#key")`，参数名 `key` 要能被编译器保留（`maven-compiler-plugin` 打开了 `-parameters`）
- `TransferService`：跨租户记账，见 [06-主从粘滞与多数据源事务](06-主从粘滞与多数据源事务.md)

`@DS("#key")` 走框架自带的 SpEL。也支持 `#header.头名称` 和 `#session.属性名`。请求头的值是 `a`，数据源键是 `tenantA`，对不上，所以这里先映射再把键传给 `@DS`，不直接用 `#header.X-Tenant-Id`。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/scenario/tenant/accounts` | 在当前租户库建账号，需要 `X-Tenant-Id` |
| GET | `/scenario/tenant/accounts` | 只读当前租户 |
| GET | `/scenario/tenant/ledgers` | 当前租户的流水 |
| POST | `/scenario/tenant/transfer` | 跨租户转账，租户在请求体里 |
| POST | `/scenario/tenant/datasources` | 注册租户库 |
| DELETE | `/scenario/tenant/datasources/{tenantId}` | 摘除运行时租户 |

```bat
curl.exe -X POST http://127.0.0.1:8000/dynamic/scenario/tenant/accounts -H "Content-Type: application/json" -H "X-Tenant-Id: a" -d "{\"accountName\":\"alpha\",\"levelName\":\"basic\"}"
curl.exe http://127.0.0.1:8000/dynamic/scenario/tenant/accounts -H "X-Tenant-Id: b"
```

租户 `a` 写入的账号，用 `X-Tenant-Id: b` 查询不到。

## 注意

1. 过滤器在请求结束时清掉租户上下文。异步线程如果还要访问数据库，要自己再设置租户。
2. 注册接口不建表。库和 `t_account`、`t_ledger` 需要先准备好，结构见 [sql/mysql-init.sql](sql/mysql-init.sql) 里租户库的两张表。
3. `LedgerWriter` 必须是另一个 Spring Bean。写在 `TransferService` 内部直接调用，`@DS` 不会生效。
