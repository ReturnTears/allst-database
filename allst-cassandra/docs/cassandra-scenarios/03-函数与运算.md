# 03 函数与运算

## 场景

报表要看一台设备某一天某个指标的次数、最小、最大、平均、合计，或者看某一行的写入时间和剩余 TTL。这些都限制在一个分区里。整表 `count(*)` 会变成全集群扫描，接口不提供。

CQL 的 `GROUP BY` 只能按主键前缀。`metric_type` 是第一个聚簇列，所以可以按指标分组。不能 `GROUP BY` 一个小时，小时桶在 [04-连续查询](04-连续查询.md) 里由应用计算。

## 用到的函数

| 函数 | 接口 | 说明 |
| --- | --- | --- |
| `count` `min` `max` `avg` `sum` | `/aggregate`、`/group` | 只统计一个分区 |
| `writetime` | `/scalar` | 微秒。不是 `recorded_at` |
| `ttl` | `/scalar` | 这一格自己的 TTL，秒。空值表示走表级 7 天 |
| `toUnixTimestamp` `toDate` | `/scalar` | 时间类型转换 |
| `token` | `/scalar`、`/token` | 分区键的 murmur3 token |
| `CAST` | `/scalar` | `CAST(sensor_value AS text)`，类型转换写死 |
| `now` `toTimestamp` `toDate` `blobAsText` | `/server-time` | 协调节点上的时间，以及 blob 往返 |
| `*` `+` | `/arithmetic` | `sensor_value * 1.8 + 32`，摄氏转华氏 |

运算和函数名不从请求里拼接。`fn` 只允许 `count`、`min`、`max`、`avg`、`sum`，每种对应一条固定的 CQL。

用户自定义函数保持关闭。`enable_user_defined_functions` 默认就是 false。脚本 UDF 已经从 Cassandra 里拿掉了，Java UDF 还要把类放到服务端 classpath，这个模块不启用。

## 代码

- `com.allst.boot.analytics.AnalyticsService`
- `com.allst.boot.cassandra.cql.Statements`

`/token` 从已有行上读取 `token(device_id, day_bucket)`。分区是空的时候返回 `found=false`，先写再查。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/cassandra/analytics/aggregate` | 一个指标的聚合，`fn` 必填 |
| GET | `/api/cassandra/analytics/group` | 按指标分组的聚合 |
| GET | `/api/cassandra/analytics/scalar` | 一行上的 writetime、ttl、token、CAST |
| GET | `/api/cassandra/analytics/arithmetic` | 固定的摄氏转华氏 |
| GET | `/api/cassandra/analytics/token` | 这个分区的 token |
| GET | `/api/cassandra/analytics/server-time` | `now()` 和 blob 函数 |

## 调用示例

先 `/seed`，从最新一行里拿到 `recorded_at` 和 `reading_id`，再查标量函数。

```bat
curl.exe "http://127.0.0.1:8100/api/cassandra/analytics/aggregate?deviceId=dev-001&day=2026-10-24&metricType=temperature&fn=avg"
curl.exe "http://127.0.0.1:8100/api/cassandra/analytics/group?deviceId=dev-001&day=2026-10-24"
curl.exe "http://127.0.0.1:8100/api/cassandra/analytics/arithmetic?deviceId=dev-001&day=2026-10-24&metricType=temperature&limit=5"
curl.exe "http://127.0.0.1:8100/api/cassandra/analytics/token?deviceId=dev-001&day=2026-10-24"
curl.exe http://127.0.0.1:8100/api/cassandra/analytics/server-time
```

标量查询把时间和主键补全：

```bat
curl.exe "http://127.0.0.1:8100/api/cassandra/analytics/scalar?deviceId=dev-001&day=2026-10-24&metricType=temperature&time=2026-10-24T04:00:00Z&readingId=替换成实际的UUID"
```

## 生产环境要注意

- `avg` 和 `sum` 在一个大分区上仍然要读很多行。分区按天切开，就是为了让这个成本有上限。
- `writetime` 用来判断谁后写谁生效，也用来排查回放把旧值盖住的问题。逻辑恢复不会保留原来的 writetime，见 [07-数据备份与恢复](07-数据备份与恢复.md)。
- `now()` 展示用可以，拿来做主键不行。
- 日期加减可以用字面量，例如 `recorded_at >= '2026-10-24 00:00:00+0000' - 2h`。接口里的时间是绑定参数，不接受调用方传来的 duration 字符串。
