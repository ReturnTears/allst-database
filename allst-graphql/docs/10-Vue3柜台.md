# 10 Vue 3 柜台

目录 `frontend/`，只依赖 Vue 3。请求封装在 `src/api/graphql.js`：`POST /graphql`，有 `errors` 就抛错。

开发时 Vite 把 `/graphql` 代理到 `http://localhost:8089`。5173 被占用时会换下一个端口，后端对 `http://localhost` 和 `http://127.0.0.1` 的任意端口都放行。

四个页签对应四类操作：

| 页签 | 查询 | 变更 |
| --- | --- | --- |
| 商品 | `products` + `categories`，带关键字、状态、分类和分页 | `createProduct` / `updateProduct` / `deleteProduct` |
| 分类 | `categories`，带出 `parent`、`children`、`productCount` | `createCategory` / `updateCategory` / `deleteCategory` |
| 客户 | `customers`，带出地址 | `createCustomer` / `updateCustomer` / `deleteCustomer`，以及地址的增删 |
| 订单 | `orders`，嵌套客户姓名和明细快照；商品下拉只取在售 | `createOrder`、状态推进、`cancelOrder`、对已取消订单 `deleteOrder` |

价格输入框的值按字符串提交，对应 `BigDecimal` 标量。商品 id、客户 id 保持 GraphQL 返回的字符串，不要先转成数字再传，避免长 id 精度问题。

页面启动时请求 `{ health }`。连不上时顶栏写明要先启动 8089。

视觉上这是一张货栈台账：左侧深色索引导航，顶部一条黄色标记，主区是表格而不是卡片墙。状态用短标签，错误用红色条，空列表说明下一步该做什么。
