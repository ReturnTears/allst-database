# 11 运行与请求示例

## 启动后端

在 `allst-graphql` 目录：

```bash
mvn spring-boot:run
```

- 接口：`http://localhost:8089/graphql`
- GraphiQL：`http://localhost:8089/graphiql`
- H2：`http://localhost:8089/h2`，JDBC URL 填 `jdbc:h2:mem:mall`

测试：

```bash
mvn test
```

## 启动柜台

需要 Node.js 18 或更高版本。

```bash
cd frontend
npm install
npm run dev
```

打开 `http://localhost:5173`。

## 在 GraphiQL 里核对一条订单

```graphql
query {
  orders(page: { page: 0, size: 5 }) {
    content {
      orderNo
      status
      totalAmount
      customer { name }
      items { productName quantity amount }
    }
  }
}
```

样例订单是林夏的明前龙井，状态为 `PAID`，金额 `256.00`。

新建分类再删除：

```graphql
mutation {
  createCategory(input: { name: "试饮装" }) { id name }
}
```

把返回的 id 填进删除：

```graphql
mutation {
  deleteCategory(id: "把上面的 id 填这里")
}
```

库存不足：

```graphql
mutation {
  createOrder(input: {
    customerId: "1"
    addressId: "1"
    items: [{ productId: "1", quantity: 9999 }]
  }) { id }
}
```

响应里应有 `extensions.code = CONFLICT`。

订阅（GraphiQL 会通过 WebSocket 发送）：

```graphql
subscription {
  orderStatusChanged {
    orderNo
    status
  }
}
```

保持这个标签页，再到柜台把对应订单点成「发货」。这里会出现一条 `SHIPPED`。

深度过大的查询会被拒绝，例如把 `children` 套二十层。正常的商品列表、订单详情都在限制以内。
