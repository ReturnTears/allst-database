# 02 工程结构

```
allst-graphql
├── pom.xml
├── src/main/java/com/allst/boot
│   ├── GraphQLApplication.java
│   ├── common          分页、校验、标量、业务异常
│   ├── config          Schema 装配、异常转换、查询深度限制
│   ├── bootstrap       样例数据
│   ├── customer        客户与地址：实体、仓库、Service、DTO
│   ├── catalog         分类与商品
│   ├── order           订单与明细、状态事件
│   └── web             @Controller 形式的 GraphQL 入口
├── src/main/resources/graphql
│   ├── root.graphqls
│   ├── customer.graphqls
│   ├── catalog.graphqls
│   └── order.graphqls
├── src/test/java       MallGraphqlTest
├── frontend            Vue 3 柜台
└── docs                本目录
```

领域代码按业务分包，而不是按 controller / service / dao 横切。GraphQL 入口集中在 `web`，因为一种传输方式要面对多个领域；真正的规则仍在各自的 Service 里。

依赖注入使用构造方法，Service 上的依赖字段是 `final`。类级别 `@Transactional(readOnly = true)`，写方法再单独标 `@Transactional`。

`spring.jpa.open-in-view=false`。事务在 Service 方法结束时关闭，所以 GraphQL 层拿到的必须已经是普通对象，不能在序列化时再去碰懒加载。
