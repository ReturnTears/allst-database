# 02 实时分析

## 场景

订单状态变化后，运营要马上看到金额、渠道、类目、省份和趋势。计算放在 Elasticsearch 聚合里完成，不把明细拉回应用再求和。

这里的“实时”指定：事件写入后刷新索引，下一次查询能看到它。默认聚合窗口是最近 2 天。48 小时以内按小时，更长按天。`interval=hour` 或 `interval=day` 可以强制指定。

## 索引

索引名 `scenario_order_event`。一条文档是一次订单事件，不是订单主表。

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| orderId、userId | keyword | 订单号、用户。用户字段做 cardinality 得到去重人数 |
| amount | double | sum、avg，以及各桶里的金额 |
| status、channel、category、province | keyword | terms 聚合 |
| eventTime | date | 窗口过滤和 date_histogram |

状态取值：`CREATED`、`PAID`、`SHIPPED`、`CANCELLED`。渠道取值：`app`、`web`、`mini`。

## 查询规范

一次搜索同时带多个聚合，`size` 只取 1 条命中，真正要的是 `total` 和 aggregations：

- `sum`、`avg` 作用在 `amount`
- `cardinality` 作用在 `userId`
- `terms` 作用在状态、渠道、类目、省份。渠道、类目、省份下面再挂一个名为 `metric` 的 sum
- `date_histogram` 使用 `calendar_interval`，子聚合同样叫 `metric`

子聚合统一命名为 `metric`，`AggregationReads` 才能用同一套读取逻辑。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/scenario/analytics/index/init` | 创建索引 |
| POST | `/scenario/analytics/seed` | 写入最近 48 小时的 48 条固定样本 |
| POST | `/scenario/analytics/events` | 写入一条新事件并刷新 |
| GET | `/scenario/analytics/report` | 聚合报表。参数 `from`、`to`、`interval` |

报表字段：`total`、`uniqueUsers`、`sumAmount`、`avgAmount`、`byStatus`、`byChannel`、`byCategory`、`byProvince`、`trend`。桶上的 `metric` 是金额合计。

## 调用示例

```bat
curl.exe -X POST http://127.0.0.1:4565/scenario/analytics/seed
curl.exe "http://127.0.0.1:4565/scenario/analytics/report?interval=hour"
curl.exe -X POST http://127.0.0.1:4565/scenario/analytics/events -H "Content-Type: application/json" -d "{\"orderId\":\"NO20001\",\"userId\":\"user-1\",\"amount\":199,\"status\":\"PAID\",\"channel\":\"app\",\"category\":\"数码\",\"province\":\"浙江\"}"
curl.exe "http://127.0.0.1:4565/scenario/analytics/report?interval=hour"
```

第二条报表应能看到刚写入的支付事件。

## 生产环境要注意

- 样例为了演示调用了 refresh。线上用 1 秒级 `refresh_interval`，由批量写入承担吞吐。
- 趋势图若要补齐没有数据的时间点，给 date_histogram 加 `min_doc_count: 0` 和 `extended_bounds`。样例使用 `min_doc_count: 1`，只返回有事件的桶。
- 金额用 `scaled_float` 或分为单位的 long 更能避免浮点误差。样例用 double 是为了映射直观。
- 事件索引按月滚动，并用别名 `order_event_current` 指向正在写入的索引。当前样例只有一个固定索引。
